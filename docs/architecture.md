# 花名册系统架构说明

## 数据源与派生视图

系统把“权威源名单”作为唯一事实来源，再按月份生成算薪与考勤派生表。派生表可以刷新和导出，但不会覆盖源名单；人员状态变化通过同步流程进入新的月份快照。

## 权限边界

1. 钉钉完成登录和组织身份确认。
2. 后端根据 UserID/组织范围返回允许读取的数据。
3. 前端仅负责展示、筛选、复核和发起受控写操作。
4. 生产环境不把全量花名册写入公共 CDN 或静态 HTML。

## 关键设计

- 以月份为边界，保证历史数据可复现。
- 对手动加人、移除、调店和离职等操作保留明确入口。
- 将“刷新数据”和“修改权威名单”分成不同动作，减少误操作。
- 所有高影响操作使用二次确认和状态提示。
