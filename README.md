# MasterFit Roster System｜花名册系统

拉伸大师内部人事花名册与月度协同工作台，统一承载在职、离职、培训期、算薪花名册、考勤花名册和社保核对等视图。

> 这是公开作品集脱敏版。真实员工数据、钉钉授权凭证和生产考勤 API 地址未随仓库发布。

## 功能

- 在职/离职/培训期人员查询与筛选。
- 算薪花名册与考勤花名册按月生成、刷新和导出。
- 员工身份、部门、职位、员工类型、入离职时间等字段的统一展示。
- 考勤接口接入、异常状态标识和前台确认流程。
- 社保核对视图：按月份对比人员范围和关键字段。
- 手动加人、移除当月记录和导入源名单。
- 钉钉登录入口与按组织权限控制的数据读取。

## 运行逻辑

```text
钉钉登录 → 身份确认 → 读取权威花名册
                    ├→ 生成算薪月快照
                    ├→ 拉取考勤并生成考勤核对
                    └→ 社保范围/字段核对
```

页面使用单 HTML 交付，后端接口通过配置注入。派生名单和月度快照与权威源名单分离，避免刷新操作误改源数据。

## 本地查看

```powershell
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

公开版的 API 地址为 `example.invalid` 占位符，因此只能查看 UI 和交互结构。私有部署时，把 `index.html` 顶部的 `masterfit-attendance-api-base` 和钉钉 Client ID 配置为真实值。

## 简历描述建议

- 负责将人事主数据、算薪月快照、考勤核对和社保核对整合到统一工作台。
- 设计源名单与派生名单分离的同步模型，降低月度操作对权威数据的误写风险。
- 通过稳定身份字段、月份快照和异常提示，提升人事数据维护的可审计性。

## 安全

禁止将员工姓名、手机号、证件号、银行卡号、薪资金额、考勤明细或钉钉 token 写入静态文件、Git 历史或公开 issue。
